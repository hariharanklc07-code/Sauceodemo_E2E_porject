
## Scenarios Covered
- Login with valid credentials
- Add product to cart → checkout → order confirmation (multiple products)
- Add and remove a product before checkout

## Getting Started

Install dependencies:
```bash
npm install
```

Run the tests:
```bash
npx playwright test
```

Run in headed mode:
```bash
npx playwright test --headed
```

View the Allure report:
```bash
allure serve allure-results
```
